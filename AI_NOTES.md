# AI Usage Notes

## AI Tools Used

* ChatGPT (OpenAI)

## How AI Was Used

AI was used as a development assistant throughout this project to support learning and implementation. Specifically, AI assisted with:

* Understanding Express.js project structure and layered architecture.
* Explaining concepts such as controllers, services, middleware, routing, and validation.
* Providing guidance on implementing REST API endpoints.
* Suggesting improvements to project organization and code readability.
* Assisting with Swagger (OpenAPI) documentation.
* Helping write and refine integration tests using Jest and Supertest.
* Reviewing documentation and improving the README.

## Implementation Responsibility

All project files were implemented, integrated, tested, and verified by me. AI-generated suggestions were reviewed, adapted where necessary, and manually tested before being included in the project.

## Verification

Every API endpoint was manually verified using:

* Swagger UI
* Integration tests (Jest + Supertest)

All automated tests pass successfully, and the documented API behavior matches the implementation.

## Reflection

Using AI accelerated development by providing explanations, code suggestions, and documentation guidance while allowing me to better understand Express.js architecture, testing, validation, and API design.
